# How to cite

This software was developed for the paper below. If you use it, please cite
**both** the paper and the software.

## Paper

Natali, M., Modanesi, S., De Santis, D., De Lannoy, G., Steele-Dunne, S.,
Flammini, A., Domeneghetti, A., Massari, C. (2026). Field-scale irrigation
estimation using Sentinel-1 and Sentinel-2 data within a soil water balance
model coupled to the Water Cloud Model. *Remote Sensing of Environment*, 346,
115639. <https://doi.org/10.1016/j.rse.2026.115639>

```bibtex
@article{Natali2026,
  author  = {Natali, Martina and Modanesi, Sara and De Santis, Domenico and
             De Lannoy, Gabri{\"e}lle and Steele-Dunne, Susan and
             Flammini, Alessia and Domeneghetti, Alessio and Massari, Christian},
  title   = {Field-scale irrigation estimation using {Sentinel-1} and
             {Sentinel-2} data within a soil water balance model coupled to
             the {Water Cloud Model}},
  journal = {Remote Sensing of Environment},
  volume  = {346},
  pages   = {115639},
  year    = {2026},
  issn    = {0034-4257},
  doi     = {10.1016/j.rse.2026.115639},
  url     = {https://www.sciencedirect.com/science/article/pii/S0034425726004098}
}
```

## Software

Natali, M. (2026). WCM_SWB_Irri: field-scale irrigation estimation with a
soil water balance model coupled to the Water Cloud Model (Version 0.1.0)
[Computer software]. Zenodo. <https://doi.org/10.5281/zenodo.22961226>

```bibtex
@software{Natali2026_WCM_SWB_Irri,
  author    = {Natali, Martina},
  title     = {{WCM\_SWB\_Irri}: field-scale irrigation estimation with a
               soil water balance model coupled to the {Water Cloud Model}},
  version   = {0.1.0},
  year      = {2026},
  publisher = {Zenodo},
  doi       = {10.5281/zenodo.22961226},
  url       = {https://github.com/martina01natali/WCM_SWB_Irri}
}
```

The DOI above (10.5281/zenodo.22961226) refers to all versions of the software and
always resolves to the latest one. Each release also has its own DOI, listed
on the [Zenodo record](https://doi.org/10.5281/zenodo.22961226); cite the version you used when
reproducing results:

| Version | DOI |
|---|---|
| 0.1.0 | [10.5281/zenodo.22961227](https://doi.org/10.5281/zenodo.22961227) |

Machine-readable metadata: [`CITATION.cff`](CITATION.cff) (GitHub's "Cite
this repository" button) and [`.zenodo.json`](.zenodo.json).
